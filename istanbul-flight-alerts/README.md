# İstanbul Uçuş Fırsatları Radarı

IST ve SAW çıkışlı vizesiz destinasyonlar için uçuş fırsatı izleme projesi.

Bu proje, profil deposundaki bağımsız `istanbul-flight-alerts/` dizininde barındırılır. Kaynak kod herkese açıktır; uçuş sağlayıcı ve posta anahtarları yalnızca GitHub Actions Secrets ile yönetilir.

Gerekli servisler tanımlanana kadar gerçek tarama ve e-posta gönderimi etkinleşmez.
